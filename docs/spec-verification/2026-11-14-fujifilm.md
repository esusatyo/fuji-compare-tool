### Convention questions

**batteryLife.** The page gives Economy and Normal mode figures. Stored values follow neither consistently:

| item | stored | economy | normal |
|---|---|---|---|
| x-t5 | 580 | 740 | **580** |
| x-h2s | 580 | 720 | **580** |
| x-t30iii | 315 | 425 | **315** |
| gfx100-ii / gfx100s-ii / gfx100rf | 540 / 530 / 820 | — | **540 / 530 / 820** |
| x-s20 | 800 | **800** | 750 |
| x-m5 | 440 | **440** | 330 |
| x-e5 | 440 | 400 | 310 (matches neither) |
| x-h2 | 560 | 680 | 540 (matches neither) |
| x-t50 | 460 | 390 | 305 (matches neither) |
| x100vi | 430 | 360 | 310 (OVF figure ~450; matches none) |

**maxBurst.** Stored values mix two conventions: the top electronic-shutter
rate including crop modes (x-t5 20, x-h2 20, x-h2s 40, x100vi 20) and the
mechanical-shutter rate (x-e5 8, x-t50 8, x-m5 8, x-t30iii 8, gfx100s-ii 7,
gfx100rf 6). gfx100-ii 9 is neither (mech 8.0 / elec 8.7). x-s20 8: the
page's mechanical maximum reads 5.0, so recheck before deciding.

**weatherSealed with accessory.** x100vi and gfx100rf are stored `true`; Fujifilm
claims weather resistance only with the adapter ring + protection filter attached.

**evfMag on hybrid finders.** x100vi stores 0.52 (OVF); EVF is 0.66×.
