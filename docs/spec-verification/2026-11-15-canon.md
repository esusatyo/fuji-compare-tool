# Spec verification — Canon — 2026-11-15

Scope command: `node .claude/skills/verify-specs/scope.js --brand canon`
→ 159 items (18 cameras, 141 lenses).

Batch plan: batch 1 = all 18 cameras; then lenses (~9 batches, uncited first).

Source for batch 1: Canon UK official spec pages,
`https://www.canon.co.uk/cameras/<slug>/specifications/` (T1), read in Chrome
via same-origin fetch (usa.canon.com geo-blocks; canon.com.au camera pages
carry only a summary). Slugs that differ: `eos-r5c`, `eos-r50v`, `eos-r6v`.
Spec-page text is collapsed accordions: read `textContent`, not `innerText`.
IBIS ratings sit in footnotes ("8-stops based on the CIPA standard"). The pages
don't state Bluetooth versions.

### Held: convention questions
- **minAperture on variable zooms.** Canon lists ranges ("22-38", "32-54", "22 / 40").
  Stored values are the *tele-end* minimum (rf-24-240 38, rf-15-30 32, rf-200-800 54,
  rf-100-500 40, rfs-18-150 32, rfs-55-210 32). The add-thirdparty-lenses
  convention says *wide-end*. Not changed until the owner picks one.
- **AF vs MF minimum focus / magnification.** Some RF-S zooms list both (rfs-10-18 AF 0.14 m /
  MF 0.086 m, AF 0.23× / MF 0.5×; rfs-18-45 AF 0.20 m / MF 0.15 m, 0.16× / 0.26×;
  rfs-18-150 AF 0.17 m / MF 0.12 m; rfs-55-210 0.73 m). Stored values match
  neither consistently. Proposed: AF figures. Not changed.

- rfs-18-150mm: Canon UK diameter 69 (stored 74.4).
