→ 159 items (18 cameras, 141 lenses).

Batch plan: batch 1 = all 18 cameras; then lenses (~9 batches, uncited first).

Source for batch 1: Canon UK official spec pages,
`https://www.canon.co.uk/cameras/<slug>/specifications/` (T1), read in Chrome
via same-origin fetch (usa.canon.com geo-blocks; canon.com.au camera pages
carry only a summary). Slugs that differ: `eos-r5c`, `eos-r50v`, `eos-r6v`.

don't state Bluetooth versions.
