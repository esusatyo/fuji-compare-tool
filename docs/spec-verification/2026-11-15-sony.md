## Batch 1: cameras (24): APPLIED 2026-11-15

Source (T1): Sony USA product pages (`electronics.sony.com/.../p/<model>`). The full spec
sheet is embedded as JSON (`"featureValues":[{"value":…}],"name":…`); fetch the HTML
from the same origin in Chrome and regex the name/value pairs. Sony Australia's
`/products/<model>/spec` has size and weight but no battery or burst figures.

All 24 match on effective megapixels (stills), weight and EVF/monitor dots. APS-C evfMag
on Sony's pages is native (1.07×); stored values are the 35mm equivalent (0.71), which
follows the convention. Dimensions match except as listed.

specSources added to all 24.

### Held
- **Burst split:** Sony's "Continuous Drive Speed" row usually doesn't say which shutter
  each rate uses. No Sony camera is converted; it needs per-model detail.
- **zv-e10-ii depth:** Sony only gives the grip-to-monitor depth (54.2; stored 57.3).
- **Battery not on the page:** fx3, fx30, fx2, fx5, zv-e1, a7r-iv. Left as they are.
